# Examples

Sample output from a `/interview-me` run, so you can see what the pipeline produces without running it yourself first.

- [`todo-reminders-spec.md`](./todo-reminders-spec.md) — a spec written by `/interview-me` using the template in `skills/interview-me/SKILL.md`. This is the input `/team-manager` expects (`/team-manager docs/specs/<slug>.md`).

`/team-manager`'s own outputs (`tmp/team/handoff.md`, `tmp/team/design.md`, `tmp/team/review-round-<N>.md`) are per-run scratch state, gitignored by design (see "Known Gotchas" in the README) — they aren't checked into the repo, so there's no sample to show here beyond the shapes already documented in the README's Domain Vocabulary section.
